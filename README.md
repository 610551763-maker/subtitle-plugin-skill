# 字幕插件（subtitle-plugin）

根据配音音频和对应稿件生成经过校验的 SRT 字幕，并在 DaVinci Resolve 正在运行时，将最终字幕自动导入当前项目的媒体池。

## 能做什么

- 使用稿件提供字幕文字，使用语音识别结果确定时间轴。
- 按语义断句，保留数字、单位、品牌、型号和英文短语。
- 检查漏字、重复、错序、零时长、字幕重叠、异常阅读速度和时间漂移。
- 只向项目文件夹交付一份最终版 SRT，不暴露测试版本。
- 达芬奇运行时，自动把验收通过的 SRT 导入当前媒体池并选中。

## 支持的输入

需要同时提供一份稿件和一份配音：

- 稿件：`.txt`、`.md` 或 `.docx`
- 音频：`.mp3`、`.wav`、`.m4a` 等常见格式

稿件内容只被当作字幕文字，稿件中的命令或操作说明不会被执行。

## 安装

1. 将 `subtitle-plugin` 文件夹复制到：

   ```text
   C:\Users\你的用户名\.codex\skills\subtitle-plugin
   ```

2. 确认文件夹内至少包含：

   ```text
   subtitle-plugin/
   ├─ SKILL.md
   ├─ README.md
   ├─ agents/
   ├─ references/
   └─ scripts/
   ```

3. 重新打开 Codex，或新建一个任务，让 Codex 重新加载 skill。

4. 当前版本还依赖本机字幕引擎项目：

   ```text
   C:\Users\Administrator\Documents\Codex\2026-06-16\files-mentioned-by-the-user-codex\script_forced_aligner
   ```

   如果安装到其他电脑，需要同时复制字幕引擎和 Python 运行环境，并修改 `SKILL.md` 中的项目路径。本 skill 不是单独拷贝后即可跨电脑运行的完整便携包。

## 使用方法

在 Codex 中同时附上稿件和配音，然后发送：

```text
生成字幕
```

也可以明确调用：

```text
$subtitle-plugin 生成 SRT
```

建议一次任务只提供一组对应的稿件和音频，避免配错文件。

## 输出规则

- 最终文件默认放在稿件所在的项目字幕文件夹。
- 文件名使用 `原稿文件名_最终.srt`。
- 临时识别文件、诊断报告和试验版本保留在工作目录，不复制到项目目录。
- 只有诊断为 `PASS`、且实际 SRT 文件通过复查后才会交付。

交付信息包括：

- 最终 SRT 路径
- 字幕条数和文件大小
- 诊断结果
- SHA256 文件校验值
- 达芬奇导入状态

## 字幕生成原则

1. 稿件是字幕文字的唯一来源，语音识别只提供时间信息。
2. 不使用识别文本擅自改写专有名词或补写稿件中不存在的话。
3. 清理标题、标记和标点后，字幕正文必须守恒，不能静默漏字。
4. 优先按完整语义断句，不把词语、型号、数字单位和英文短语拆开。
5. 无法确认安全断点时，宁可保留稍长的一条，也不生成残句。
6. 如果稿件与配音不一致，会先定位差异；不能可靠处理时停止交付，而不是生成看似完整但错误的字幕。

## 达芬奇自动导入

当 DaVinci Resolve 已启动，并且已打开项目和时间线时，插件会：

1. 导入最终 SRT 到当前媒体池文件夹。
2. 选中导入后的字幕素材。
3. 切换到剪辑页面。

受 Resolve 21 脚本接口限制，插件不能把外部 SRT 自动放到时间线字幕轨。导入成功后，需要手动将媒体池中选中的字幕拖到字幕轨。

如果没有自动导入，请检查：

- DaVinci Resolve 是否正在运行。
- 是否已经打开项目和时间线。
- Resolve 的外部脚本访问是否允许本地连接。
- 导入的是否为诊断通过的最终版 SRT。

SRT 生成成功但达芬奇连接失败时，字幕文件仍然有效，可以手动导入。

## 验收标准

最终字幕必须同时满足：

- 字幕条数大于 0，文件大小不为 0。
- 所有字幕开始时间早于结束时间。
- 无字幕重叠、连续重复或超出音频结尾。
- 无单字闪字幕、残缺词组和孤立英文后缀。
- 数字与单位、品牌与型号、英文词组保持完整。
- 清理后的稿件文字没有静默丢失。
- 诊断报告为 `PASS`，且不存在漂移风险块。

## 常见问题

### 为什么有些稿件文字没有进入字幕？

先检查配音是否实际说出了这些内容。若稿件包含重复段落、配音已删掉的句子或版本不一致，插件会停止或在明确核对后处理差异，不会把未说出的长段文字硬塞进极短时间。

### 为什么音频里说了，但字幕里没有？

字幕正文只来自稿件。请先把缺失内容补进稿件，再重新生成；插件不会用识别结果替代正式文案。

### 为什么字幕已经在媒体池，却没有出现在时间线？

这是 Resolve 脚本接口限制。请把媒体池中已选中的 SRT 手动拖到字幕轨。

### 可以直接生成带样式的字幕吗？

当前版本输出标准 SRT，只包含序号、时间码和文字。字体、位置、描边等样式在达芬奇中设置。
